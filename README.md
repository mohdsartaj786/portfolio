# 🌐 Mohd Sartaj Hashmi — Personal Developer Portfolio

A modern, responsive, and SEO-optimized personal portfolio website showcasing my web development projects, technical skills, freelance services, and contact details.

🔗 **Live Website:** [https://mohdsartaj786.github.io/portfolio/](https://mohdsartaj786.github.io/portfolio/)

---

## ✨ Features

- **Custom Color Palette:** Built with a refined Dark Forest Green (`#0f1c14`), Warm Beige (`#e9d7b9`), and Deep Maroon (`#58181d`) theme.
- **Responsive Auto-Adjusting Layout:** Uses CSS Grid (`repeat(auto-fit, minmax(250px, 1fr))`) and Flexbox to adapt seamlessly across desktop, tablet, and mobile screens.
- **Interactive UI & Animations:** Includes smooth scroll-reveal animations (`IntersectionObserver`), active navigation highlighting, mobile hamburger menu, floating back-to-top button, and toast notifications.
- **Direct Client Communication:** One-click WhatsApp chat integration, pre-filled Gmail compose links, clickable phone actions, and downloadable PDF resume.
- **SEO & Social Preview Ready:** Configured with Open Graph (OG) tags, Twitter cards, Schema.org Person JSON-LD markup, `sitemap.xml`, and `robots.txt` for Google Search indexing.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Icons & Typography:** Font Awesome 6, Devicon, Playfair Display, Plus Jakarta Sans, Caveat
- **Deployment & SEO:** GitHub Pages, Google Search Console, Schema.org
